# Hidden Stories

A buildless, responsive hospitality experience. Serve the extracted folder with any static host. `index.html` and `assets/` are at the root. There are no runtime dependencies; the one third-party request is Google Fonts, for the condensed display face (Noto Serif Display) and the script (Pinyon Script).

## Structure

- `index.html`: semantic page sections, navigation and dialog shells.
- `styles.css`: base layouts and accessibility overrides.
- `reference-layout.css`: detailed reference compositions and responsive overrides.
- `START-HERE.txt`: preview, deployment and image-quality notes.
- `scenes.js` / `story.css`: the scroll story — the two rising domes, the photograph that grows to full screen, the sideways journey and city map, the parting clouds, the home kinds opening from slivers, the dusk feature list, burgundy panels, line-by-line reveals and smooth wheel scrolling.
- `app.js`: starts the story, the interaction layer and the booking platform.
- `platform.js` / `platform.css`: the booking platform, following https://www.hiddenstories.in/. It adds the home blocks below the story (search, categories, featured stays, collections, why us, guest quotes) and these screens: Explore (`#/stays`, with price, type, bedroom, amenity and collection filters, guests, availability, sort and grid/map view), Stay (`#/stay/<id>`), Booking (`#/book/<id>`, Dates → Guest Details → Payment → Confirmation), Sign in (`#/login`: email, Google, phone OTP), Wishlist, Trips, Inbox and Profile.
- `store.js`: accounts and saved data — Firebase Auth + Firestore when `firebase-config.js` is filled in, otherwise a demo mode that keeps everything in the browser.
- `firebase-config.js`, `firestore.rules`, `FIREBASE-SETUP.md`: Firebase connection, security rules and the step-by-step setup guide.
- `maps.js` / `maps-config.js`: Google Maps in Explore → Map. Without a key it embeds Google Maps for the chosen stay's neighbourhood; with a Maps JavaScript API key every matching stay becomes a price pin on one interactive map.
- `site-data.js`: platform content shared with the live site — hosts, featured reviews, testimonials, house rules, cancellation policy, categories and collections.
- `logic.js`: filtering and date/price calculations.
- `experience.js` / `experience.css`: the arch intro, home-tour chapters, collection reveals, ruby button fills, booking bar, back-to-top and the Hyderabad clock.
- `assets/home-tour-*.mp4`: the hero home-tour film (1920×1080 and a 720×1280 portrait cut for phones), rendered from the catalogue photographs with slow camera moves and a warm grade; posters alongside. Re-render with `python source/render-home-tour.py assets assets/home-tour-1920.mp4 1920 1080 24 assets/home-tour-poster.webp` (needs Python with OpenCV and ffmpeg).
- `assets/bougainvillea-*.webp`, `assets/clouds-*.webp`: transparent flower and cloud cut-outs generated by `source/bougainvillea.py` and `source/clouds.py` (Python with Pillow, NumPy and OpenCV).
- `catalogue.js`: eight property records sourced from the supplied website.
- `assets`: local photographs, fonts, supplied launch-film logo frame and optimized launch film.
- `source/catalogue.json`: the source catalogue as retrieved on 8 October 2026.

## Source and brand fidelity

The three supplied reference screenshots informed, in order: the framed hero and editorial navigation; the cream asymmetric body; and the stay collection. The revision restores the exact canoe illustration, two-tier navigation, framed room carousel, villa carousel with hotspots, ornamental editorial heading, mission grid, corner-framed experiences, and aligned six-card collection. The six coastal cards use the original recovered Atlanta Trevone photos and truthful names in a separate inspiration edit; they link to that owner and are not represented as Hidden Stories inventory. The eight Hyderabad property records remain unchanged in their own collection.

The supplied launch video carries the burgundy figurative Hidden Stories logo, which differs from the public site's green doorway emblem. This experience uses the original film logo as a CSS window onto an unretouched video frame. The entire emblem remains visible. The launch-kit archive/font files were not present in the available attachments or located by Library search. Playfair Display and Inter are self-hosted from the font families declared by the supplied public website. A standalone original logo and the full brand kit would enable final brand-level verification.

Property names, locations, capacities, amenities, nightly rates and photographic source IDs are taken from https://www.hiddenstories.in/ and its publicly served catalogue. Descriptions are rewritten without adding property claims. Reviews, host profiles, testimonial claims and simulated payments from that source have not been carried over.

The catalogue references Unsplash photos; this implementation retains those exact source photographs and creates responsive local WebP encodings. The reference revision also includes original public photography from Atlanta Trevone and Toscana Valley, and the original canoe artwork from Grand Adirondack. No AI redrawing or photo upscaling was used. Original source URLs and native dimensions are recorded in source/reference-image-audit.json and source/image-resolution-audit.json. The published page does not load third-party JavaScript bundles. Supplied screenshots and the original film are kept in `references/` and are not used by the published page.

## Image-resolution limits

Fourteen catalogue photographs have native-source 3840px-wide WebP versions, with smaller responsive encodings. One catalogue photo is capped at 3024px. The six reference-three photographs are 1024–2286px wide, up to 3200px tall. The canoe is 830×344px and is displayed small. The first reference room-rendering URL returned access errors; the existing sharp native-source room photograph remains. Several exact second-reference photographs could not be located in high-resolution form, so related official Toscana Valley images are used. This is a closer structural recreation, not a claim of pixel-exact or all-4K fidelity.

## Booking scope

Guests can search, filter, save, book, cancel, message hosts and review stays. Bookings are "reserve now, pay later": no card or UPI details are collected on the site, instant-book stays are held straight away and the rest are sent as requests. Each booked night is stored as its own record, so the same night can never be booked twice. With Firebase connected, accounts and data are real and shared across devices; in demo mode they stay in the visitor's browser. The ratings, review counts, host names, featured reviews and guest quotes come from the live hiddenstories.in site; make sure they reflect real guests before launch.

## Motion and accessibility

Mouse-wheel scrolling glides with gentle inertia; touch scrolling stays native. Scenes update in a requestAnimationFrame loop only while scrolling or resizing. A cream dome rises over the hero film, and photographs grow, open and drift as you scroll. Horizontal storytelling is pinned on desktop and touch-scrollable on mobile. Reduced-motion mode removes pinned travel and entrance motion. Dialogs are native, keyboard accessible and labelled. Search controls have native labels and date constraints.

## Validation limit

Static assets, source links, JS syntax, filtering and date behaviour can be checked in the execution environment. The required managed browser-control skill was not available, so an actual browser visual/responsive QA pass could not be performed here.

## Original reference film

All deployed images, fonts and the playable website film are ordinary files in `assets/`. The original 58 MB source film is preserved byte-for-byte in `references/original-film/` because the GitHub upload API rejected the single large file. It is not needed to deploy the website. To restore the original MP4 after cloning, run:

```sh
python3 references/original-film/restore.py
```

The script checks every part and the restored video against SHA-256 checksums.
